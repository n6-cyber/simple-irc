# Setup
How to set up this server? Quite simple heres an example this is what you do:
    `git clone https://github.com/n6-cyber/simple-irc.git`
    `cd simple-irc`
    `python server.py`
    `input server ip for example: 127.0.0.1`
    `input server port for example: 6667`
    `python client.py`
    `choose colors on or off: yes`
    `input server ip: 127.0.0.1` (in this example)
    `input server port: 6667`
    `choose username: n_6` (in example)
    `n_6[time]: start chatting!!`
    `/help` to see avaliable cmds
    `color"word"` (to add color to text)
    `red"word"` (in this example making it red)
